Operational notes:
- Staging worker must run:
  php artisan queue:work --queue=push,smart-home,default --tries=3 --sleep=3 --timeout=90
- Required env:
  PUSH_PROVIDER=fcm
  FIREBASE_PROJECT_ID
  FIREBASE_PRIVATE_KEY
  FIREBASE_CLIENT_EMAIL
