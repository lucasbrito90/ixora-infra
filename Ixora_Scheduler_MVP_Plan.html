IXORA Scheduler MVP - Implementation Plan

  5. Backend Schedule CRUD + Pest
  6. Dispatcher Command

Core Decisions

  • Backend = source of truth
  • SQLite = offline read-only mirror
  • No offline create/edit/delete
  • Timezone belongs to each schedule
  • Local Notifications for offline reminders
  • DigitalOcean Scheduled Job for dispatching
  • Queue Worker + FCM in future phase
